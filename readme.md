# CMDL / AC-GATE

> A testable framework for **entity-conditioned heterogeneous lag discovery** in panel time series.

This repository contains the reference implementation, baselines, real-data pipelines, ablations and 20-seed locked outputs that back the paper **AC-GATE: Auditing Heterogeneous Delays in Panel Time Series**.

---

## 1. What this repository provides

- `model/` — AC-GATE: Adaptive Conditioning Encoder + Scale-Invariant Lag Gate + LSTM backbone, plus a domain-agnostic loss with optional reconstruction regularisation.
- `baselines/` — Plain LSTM (no AC, no lag gate), Grouped ARDL (per–anchor-group distributed-lag OLS), and a Panel OLS reference. **TFT is not included in the 20-seed evaluation suite** (see [§4 Baselines](#4-baselines)).
- `data/` — Loaders and download scripts for two real-world country-level panels (Penn World Table 11.0 + OWID-energy × WGI) and a synthetic generator with ground-truth `k*`.
- `experiments/` — Self-contained runners; `experiments/run_complete_20seed_suite.py` is the single entry point that reproduces all paper artefacts.
- `evaluation/` — Metrics (`metrics.py`), paired Wilcoxon significance (`significance.py`), real-data diagnostics (`realdata_diagnostics.py`) and the **stratified k\*** L2 mechanism test (`stratified_kstar.py`).
- `notebooks/` — Final-figure notebooks for synthetic, economics and energy domains.
- `outputs/notebook_*/complete_20seed_20260426/` — Locked 20-seed comparison CSVs reported in the paper.

## 4. Baselines

All baselines share the same data loader, train/val/test split, optimiser, and 20 seeds (`SEEDS = list(range(20))`). See [§5 Hyperparameter Protocol](#5-hyperparameter-protocol) for shared backbone hyperparameters.

| Method | Implementation | Reference | In 20-seed suite | Role |
|---|---|---|---|---|
| **CMDL / AC-GATE** (ours) | `model/cmdl_model.py` (self) | This work | ✅ | Main method |
| Plain LSTM | `baselines/lstm_baseline.py` (self) | — | ✅ | Neural baseline without AC encoder / lag gate |
| Grouped ARDL | `baselines/grouped_ardl.py` (self, on `linearmodels.PanelOLS`) | Pesaran & Smith (1995) | ✅ | Anchor-grouped distributed-lag OLS — strong econometric baseline |
| Panel OLS | `baselines/panel_ols.py` (self, on `linearmodels.PanelOLS`) | — | ⚪ Reference only | Used as a sanity-check during data preparation; not tabled in the paper |
| Ablation: No AC Encoder | `experiments/run_*_ablation.py` (variant `no_ac_encoder`) | This work | ✅ | Removes AC conditioning |
| Ablation: Uniform Lag | `experiments/run_*_ablation.py` (variant `uniform_lag`) | This work | ✅ | Disables lag gate ($\omega_k = 1/K$) |
| Ablation: No Recon Reg | `experiments/run_*_ablation.py` (variant `no_recon_regularization`) | This work | ✅ | Sets $\lambda_r = 0$ |


**Note on TFT.** The 20-seed locked panels are small (a few thousand observations per domain) and exhibit short time dimensions (≤ 30 years post-window). Under this regime a Transformer-based forecaster offers no expressive advantage over the LSTM backbone; furthermore, TFT assumes a homogeneous lag structure across entities, which is exactly the assumption AC-GATE relaxes. We therefore cite TFT only as a design reference for the gated-residual block (`model/lag_gate.py`) and exclude it from the comparative tables to avoid a selectively unfavourable baseline. A self-implemented TFT runner is **not** maintained in this repository.

## 5. Hyperparameter Protocol

All methods share the same backbone hyperparameters defined in `experiments/run_complete_20seed_suite.py` via `synthetic_common_args` / `economics_common_args` / `energy_common_args`. **No hyperparameter search was performed**; values are the Step-4 synthetic defaults carried over to the real domains without retuning. This is a deliberate design choice to enforce a strict apples-to-apples comparison.

| Group | Parameter | Value | Notes |
|---|---|---|---|
| Optimiser | optimiser, learning rate | Adam, `1e-3` | Same across all methods |
| Optimiser | gradient clipping | `1.0` (mode = `global` for synthetic/energy, `split` for economics) | `split` clips main / proxy parameters separately |
| Schedule | epochs, early-stopping patience | synthetic 200/20, economics 120/20, energy 120/20 | Patience on validation loss |
| Backbone (shared) | `d_model`, `lstm_layers`, `dropout` | 64, 2, 0.05 | Defined in [config/cmdl_config.py](config/cmdl_config.py); inherited by Plain LSTM |
| Backbone (shared) | entity embedding dim | 8 | |
| AC-GATE specific | `lambda_r` (proxy reconstruction weight) | 0.1 | Single CMDL-only knob; ablation `no_recon_regularization` sets it to 0 |
| AC-GATE specific | `temperature` (ω softmax τ) | 1.0 | |
| AC-GATE specific | `lag_bias_strength` (relative position bias) | 1.0 | |
| AC-GATE specific | `omega_transform` | `softmax` | Sparsemax retained as a code option only |
| Real-data only | `feature_bundle` | economics: `effective_labor_aware`; energy: `minimal` | Documented in `*_loader.py` |
| Real-data only | `max_missing_share` | 0.15 | Per-row missing threshold |
| Real-data only | `recon_loss_mode` | economics: `anchor_weighted`; energy: default MSE | |
| Reproducibility | seeds | `list(range(20))` | Fixed across Python / NumPy / PyTorch (CPU) inside `set_seed` |
| Reproducibility | device | CPU | All locked outputs were produced on CPU; no `cuDNN` determinism switch is required |

The Plain LSTM baseline inherits `d_model`, `lstm_layers` and `dropout` from `CMDLConfig` so that any predictive gap reflects the AC encoder + lag gate, not capacity differences.

## 8. Method

For each entity $i$, AC-GATE encodes a small set of static proxy variables $\mathbf{p}_i$ into a scalar absorption score $z_i = f_\phi(\mathbf{p}_i)$. A **scale-invariant lag gate** maps $z_i$ to an entity-specific lag-weight distribution

$$\omega(k\mid z_i) = \mathrm{Softmax}\!\left(\tfrac{g_\theta(z_i) - \lambda \cdot k/K}{\tau}\right),\qquad k = 1,\dots,K,$$

which weights past treatments to form the per-entity context $c_{i,t} = \sum_{k=1}^{K} \omega_{i,k}\, X_{i,t-k}$. An LSTM backbone consumes $[c_{i,t}; \text{entity\_emb}_i; \mathbf{s}_i; \mathbf{c}_t]$ and a regression head emits $\hat{Y}_{i,t+1}$. Training minimises $\mathcal{L}_{\text{task}} + \lambda_r \mathcal{L}_{\text{recon}}$ where $\mathcal{L}_{\text{recon}}$ is the proxy reconstruction MSE that anchors $z_i$ to the input proxies. The interpretable byproduct is the **per-entity effective lag** $k_i^* = \sum_k k\, \omega_{i,k}$, computed at inference. Full derivations: [paper_strategy.md §1](paper_strategy.md).
