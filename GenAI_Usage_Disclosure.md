# GenAI Usage Disclosure

This repository used GitHub Copilot Chat in Visual Studio Code as an AI-assisted programming tool during code review, implementation support, documentation drafting, and reproducibility-audit cleanup.

The tool was used for the following tasks:

- Code assistance: generating small code patches, refactoring suggestions, and test scaffolding.
- Code review support: identifying reproducibility, fairness, and engineering risks for author review.
- Experiment-analysis support: organizing existing experiment outputs into audit-ready summaries.

The tool was not used to fabricate experimental data, alter raw datasets, choose favorable seeds, or generate unsupported scientific conclusions. All AI-assisted outputs were manually reviewed, edited, and accepted by the authors before inclusion. The authors remain responsible for the correctness of the code, experiments, documentation, and claims.

For anonymous review, author-identifying details are intentionally omitted from this disclosure.
